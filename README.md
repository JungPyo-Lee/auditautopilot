# auditautopilot

회계감사 중간·기말 업무 자동화 도구. 설계서: [감사업무 자동화 시스템 설계서](https://claude.ai/artifact/14tNiAD9BqWFPDhNwmcY1A)

지금 들어 있는 기능 (2단계: 핵심 계산)

| 기능 | 명령 | 설명 |
| --- | --- | --- |
| 조서 정리 | `workpaper prepare` | 절차서 탭 숨김, 담당자별 탭만 보기, 맨 앞 목차 시트, 깨진 이름 정의(#REF!) 정리 |
| 인쇄용 사본 | `workpaper print-copy` | 절차서 탭까지 모두 보이는 사본 |
| 데이터 불러오기 | `import semusarang`, `import douzone-journal` | 내보내기 엑셀을 표준 형식으로 정리 (주민등록번호 뒷자리 가림) |
| 중요성 | `materiality` | 전체·수행중요성, 명백히 사소한 금액. 중간감사는 연환산 |
| 분석적 검토 | `analytics` | 전기 대비 증감, 기준 초과 계정 표시, 질문서 초안, 월별 추이 |
| 표본추출 | `sample` | 기준금액 이상 전수, 무작위, 체계적, 금액단위(MUS). 시드값 기록 |

3단계: 관리 화면 (`serve`)

| 기능 | 설명 |
| --- | --- |
| 회사·감사 등록 | 회사코드, 담당자 이메일, 업종(일반·건설). 감사 등록 시 감사준비자료 양식으로 요청 목록 자동 생성 |
| 자료요청(PBC) 관리 | 항목별 상태(미요청·요청·일부수령·수령·검토완료·보완요청·해당없음), 요청일·수령일, 비고. 엑셀로 내려받기 |
| 메일 일정 | 현장감사 D-7 최초 요청, D-3부터 당일까지 매일 미제출 항목만 독촉. 주말·공휴일 건너뜀(설정) |
| 메일 보내기 | 오늘 보낼 메일을 현황 화면에 띄우고 [지금 보내기](메일 계정 연결 시) 또는 아웃룩용 .eml 내려받기. 자동 발송을 켜면 매일 정한 시각에 보냄 |
| 메일 받기 | 연결한 메일함을 주기적으로 확인해 회사 담당자(주소·회사 도메인) 또는 제목의 [C001-2026-기말] 꼬리표로 감사를 찾고 첨부를 폴더 규칙대로 저장. 대용량 링크는 감사 화면에 모아 보여줌. 읽음 표시는 바꾸지 않음 |
| 받은 자료 정리 | 화면에서 올리거나 수신함 폴더에 넣으면 폴더 규칙대로 저장, 파일명의 요청번호·자료명으로 항목을 찾아 '수령' 처리. 못 찾은 파일은 미분류 폴더 |
| 폴더 규칙 | `{루트}/{회사순번:02}.{회사명}/...` 처럼 칸을 조합. JP님 현재 규칙과 제안 규칙을 미리 넣어 둠 |

## 설치

Python 3.10 이상([python.org](https://www.python.org/downloads/) 설치본)이 필요하다.
필요한 패키지는 openpyxl 하나뿐이다.

```
python -m pip install -e ".[dev]"
```

윈도우 스마트 앱 컨트롤·회사 앱 제어 정책은 서명 없는 DLL(pandas, numpy, lxml 등)과
가상환경의 `pip.exe`를 막는다. 그래서 이 도구는 순수 파이썬 패키지만 쓰고,
설치는 `pip` 대신 `python -m pip`으로 한다. 새 기능에도 컴파일된 패키지를 추가하지 않는다
(`tests/test_cli.py::test_no_compiled_packages_are_imported`가 확인한다).

## 사용 예

```
# 조서: 내 담당 인덱스만 보이게 + 목차 + 깨진 이름 정리 (원본은 그대로 두고 새 파일로 저장)
python -m auditautopilot workpaper prepare 입증감사조서.xlsx -o 조서_작업용.xlsx --assignee 홍길동

# 인쇄용 사본 (절차서 탭 포함 전체 표시)
python -m auditautopilot workpaper print-copy 입증감사조서.xlsx -o 조서_인쇄용.xlsx

# 세무사랑 '재무제표 등' 파일 정리
python -m auditautopilot import semusarang 재무제표등.xlsx -o 정리.xlsx

# 중요성: 파일에서 매출액을 찾아 9개월이면 자동 연환산
python -m auditautopilot materiality 재무제표등.xlsx --benchmark 매출액 --overall-pct 1 -o 중요성.xlsx

# 분석적 검토: 수행중요성 이상이면서 10% 이상 변동한 계정
python -m auditautopilot analytics 재무제표등.xlsx -o 분석적검토.xlsx --threshold-amount 858395000

# 관리 화면 열기 (브라우저가 자동으로 열린다. 끝내려면 Ctrl+C)
python -m auditautopilot serve

# 표본: 외상매출금(108) 거래처 잔액에서 10억 이상 전수 + 나머지 MUS 25건
python -m auditautopilot sample 재무제표등.xlsx --account 108 --threshold 1000000000 --method mus --n 25 -o 표본.xlsx

# 더존: 재무상태표·손익계산서·거래처원장·분개장을 함께 주면 종류를 알아서 맞춘다
python -m auditautopilot import douzone 재무상태표과목별.xlsx 손익계산서과목별.xlsx "거래처원장 (1).xlsx" -o 정리.xlsx
python -m auditautopilot analytics 재무상태표과목별.xlsx 손익계산서과목별.xlsx -o 분석적검토.xlsx --threshold-amount 266196000
python -m auditautopilot sample 재무상태표과목별.xlsx "거래처원장 (1).xlsx" --account 외상매출금 --threshold 500000000 -o 표본.xlsx
```

## 채권채무 조회 (전자조회 회신현황)

한공회 채권채무 전자조회(NICE 감사지원 서비스, https://kicpa.nicebizline.com)에서 회신현황·미회신현황을 가져와 대사표를 만든다.

- 설정 > 전자조회 계정에 회계사 본인 아이디·비밀번호를 넣고 [로그인 시험]을 누르면 프로젝트 목록을 불러온다.
  비밀번호는 데이터베이스에 저장하지 않는다(메일 비밀번호와 같은 방식).
- 감사 건 페이지 [채권채무 조회]에서 [전자조회에서 지금 가져오기]를 누르면 회사 이름·연도로 프로젝트를 찾아 연결하고
  (못 찾거나 틀리면 목록에서 직접 고른다) 회신현황·미회신현황 엑셀을 받아 '채권채무조회' 분류 폴더에 저장한다. 내용이 같으면 다시 저장하지 않는다.
- 회신 판정: 미회신 금액(원화 합계)이 감사 건에 넣은 중요성 금액을 넘거나, 회신률(회신 건수 ÷ 조회 건수)이 기준(기본 80%,
  설정 > 전자조회 계정에서 변경)보다 낮으면 감사 건의 채권채무 조회 카드가 빨간 테두리로 바뀌고 현황 화면에 빨간 표시가 붙는다.
  외화 미회신 건은 환산하지 않아 금액 합계에서 빠지며 화면에 따로 알린다.
- [하루 한 번 자동으로 가져오기]를 켜면 프로젝트가 연결된 감사 건을 발송 시각 이후 하루 한 번 가져온다.
- 이용약관 제9조는 ID 공유와 감사 목적 외 이용을 금지한다. 팀원은 각자 자기 아이디를 쓴다.
  비밀번호를 여러 번 틀려 자동입력방지 문자가 나오면 사이트에서 한 번 직접 로그인한 뒤 다시 시도한다.

사이트에서 직접 내려받은 엑셀(기업명·구분·발송금액·회신금액·일치여부·회신일시)을 올리거나 명령으로 실행해도 된다.

```
python -m auditautopilot confirm 회신현황.xlsx -o 채권채무조회.xlsx
python -m auditautopilot confirm 회신현황.xlsx 재무상태표과목별.xlsx "거래처원장 (1).xlsx" "거래처원장 (2).xlsx" -o 채권채무조회.xlsx
```

- 시트: 요약(계정별 일치·불일치·미회신 건수와 금액, 조회 비율) / 불일치_차이조정 / 미회신_대체절차 / 명세 / 참고
- 구분 '외상매출금(커머스)'는 외상매출금으로, 영문 'accounts receivable'은 외상매출금으로 묶는다. 같은 거래처를 여러 차수로 보냈으면 마지막 차수를 쓴다.
- 재무상태표·거래처원장을 함께 주면 발송금액이 장부 잔액과 같은지 거래처별로 다시 확인하고(이름의 (주)·주식회사 표기 차이는 무시),
  계정별 조회 비율(발송금액 ÷ 재무상태표 잔액)을 낸다.
- 외화 건은 환율을 곱하지 않으므로 원화 합계·조회 비율에서 빠진다. 회신 금액 단위가 발송과 크게 다르면 '확인할 점'에 표시한다.
- 불일치는 차이조정, 미회신은 대체적 절차 대상이다 (감사기준서 505 '외부조회' 문단 12 미회신·문단 14 예외사항.
  국제감사기준 ISA 505와 같은 구성: [ICAEW 해설](https://www.icaew.com/technical/audit-and-assurance/faculty-resources/implementing-isas/external-confirmations-in-an-isa-audit),
  [ISA 505 원문 (IAASA)](https://iaasa.ie/wp-content/uploads/2022/09/ISA505I.pdf)).
- 금융기관 조회는 아직 다루지 않는다.

## 질문서 (작성 → 승인 → 발송 → 답변)

감사 건 페이지 [질문서]에서 관리한다.

- 질문 추가: 계정·질문·금액을 넣는다. [채권채무 조회 불일치·미회신으로 초안 만들기]는 가져온 회신현황의 불일치·미회신 건마다 질문 초안을 만든다(같은 건은 한 번만).
- 상태: 작성 → 승인대기 → 승인 → 발송 → 답변받음 → 종결. 작성·승인대기 상태에서만 고치거나 지울 수 있다.
- 승인: 고른 질문에 [승인]. 승인자는 설정의 작성자 이름과 날짜로 남는다(팀 로그인 전까지).
- 발송: 승인한 질문만 메일로 보낸다. 본문에 질문 표, 첨부로 답변 칸이 있는 질문서 엑셀. 제목에 감사코드가 들어가 답장이 같은 감사 건으로 들어온다.
  문구와 회신기한(보낸 날 + n일)은 설정 > 메일 문구에서 바꾼다.
- 답변: 회사가 답변 칸을 채운 질문서 엑셀을 메일로 보내면(파일 이름에 '질문서') 자동으로 답변이 들어가고 '질문서' 폴더에 저장된다.
  [답변 엑셀 반영]으로 직접 올려도 된다.

### 장부로 증감분석 질문 초안 만들기

[질문서] 카드에서 회사 자료(재무상태표·손익계산서 과목별(전기 금액 포함), 분개장, 거래처원장 또는 세무사랑 묶음 파일)와
중요성 금액(비우면 채권채무 조회에 넣은 값)을 넣고 [장부로 증감분석 질문 초안 만들기]를 누르면 아래 질문이 '작성' 상태로 들어간다.
같은 질문(같은 계정·같은 전표)은 다시 넣지 않으므로 자료를 바꿔 여러 번 눌러도 된다.

1. 증감: 전기 대비 증감액이 중요성 금액 이상인 계정마다 증감 사유. 중간감사 손익은 12개월로 환산해 비교한다(10개월이면 × 12/10).
   결산 전 손익계산서(매출원가 0원)이면 매출원가 구성 항목·재고자산·미처분이익잉여금은 뺀다.
2. 대손: 외상매출금·받을어음 잔액이 전기와 같은 경우, 거래처원장에서 기초 잔액 그대로 당기 거래가 없는 거래처,
   대손충당금이 전기와 같은 금액인 경우 대손충당금 설정 여부를 묻는다.
3. 원가율: 매출원가 ÷ 매출액이 전기 대비 3%p 이상 바뀌면 사유. 결산 전(매출원가 0원)이면 건너뛰고 알려 준다.
4. 특이분개: 분개장 전표(일자+전표번호)마다 점수를 매겨 최대 10건. 주말·양력 공휴일(설·추석은 날짜가 바뀌어 주말만 잡힘),
   매출 차변, 매출 상대계정이 채권·현금·부가세·선수금이 아닌 경우, 결산분개, 적요의 수정·정정·오류·취소·가수금·가지급(계정대체·조정은 약하게),
   마이너스 금액, 중요성 이상, 백만원 단위로 딱 떨어지는 큰 금액, 적요 없는 큰 금액, 기간 말 5일 이내 큰 금액.
   금액만 큰 평범한 거래는 고르지 않는다.
5. 표본: 매출전표(매출 계정 대변)와 매입전표(상품·원재료·부재료 등 차변 또는 외상매입금 대변)에서 무작위 5건씩 증빙 요청.
   시드값을 질문에 남기므로 같은 시드를 넣으면 같은 표본이 다시 나온다. 이미 뽑은 표본이 있으면 다시 뽑지 않는다.
   질문서 엑셀에 '요청자료' 탭(전표일자·전표번호·거래처·금액·요청 자료·제출 여부)이 따로 생긴다.

모두 초안이다. 회계사가 고치고 승인한 질문만 나간다.

## 리드시트·거래처 명세 (조서 채우기)

```
python -m auditautopilot leadsheet 조서_작업용.xlsx 합계잔액시산표.xlsx 재무상태표.xlsx 손익계산서.xlsx 거래처원장*.xlsx -o 조서_리드시트.xlsx
```

관리 화면에서는 감사 건 페이지 [리드시트·거래처 명세]에 조서 양식과 회사 자료를 올리면 된다(결과는 '조서' 폴더에 저장).

- **TB 탭**: 시산표 계정을 조서 묶음(A 현금및현금성자산, C 매출채권, AA 매입채무 …)의 칸에 차례로 넣는다(F 과목, D·E·G·H 금액).
  묶음은 시산표 구분(당좌자산, 투자자산, 유동부채 …)과 과목명으로 정한다. 차감계정(대손충당금, 감가상각누계액 등)은
  바로 앞 계정과 같은 묶음에 넣고 증가·감소·검증 수식을 차감계정용으로 바꾼다.
- **BS 탭**: 당기(D)는 시산표 잔액, 전기(F)는 재무상태표(과목별)의 전기 금액. 차감계정은 음수.
  TB 탭 기초잔액이 BS 탭 전기를 끌어 쓰므로 리드시트(○1000)의 기초·증가·감소·기말이 저절로 계산된다.
- **IS 탭**: 손익계산서(과목별)의 당기·전기. 없으면 시산표 금액만 넣는다. 매출원가의 기말재고·타계정대체는 음수.
- **리드시트 B열**에는 계정코드를 넣는다.
- **양식 고치기**: TB 탭 합계 수식에 빠진 묶음(예: 재료비·노무비·경비, 비유동 매출채권·매입채무)을 더하고,
  과목이 대손충당금인데 일반 자산 수식인 칸은 차감계정 수식으로 바꾼다. 채울 때마다 자동으로 하며,
  빈 양식만 고치려면 `leadsheet 조서.xlsx --fix-template -o 고친양식.xlsx` (남은 예시 금액도 지움).
- **마감 전 시산표**: 당기 손익이 이익잉여금에 안 들어가 있으므로 BS 탭 미처분이익잉여금 당기 금액에 더해 대차를 맞춘다
  (TB 탭·리드시트는 시산표 잔액 그대로).
- **○1100 탭**: 거래처원장마다 그 계정 묶음의 ○1100 탭 '감사절차 및 감사결과' 아래에 거래처별 명세
  (전기이월, 차변, 대변, 잔액, 구성비, 합계)와 시산표 잔액(`=TB!L…`)·차이를 쓴다. 칸이 모자라면 행을 넣어
  아래 '차이발견사항' 표를 밀어 내린다(병합·수식도 같이).
- 묶음 칸이 모자라거나 넣을 곳을 못 정한 계정은 결과 목록에 나온다. 조서에 행을 늘린 뒤 다시 하면 된다.
- 엑셀이 열 때 다시 계산하도록 해 둔다(저장된 옛 계산값은 지움).
- 회사가 준 시산표를 조서에 옮겨 적는 것이며 재무제표나 주석을 대신 작성하지 않는다
  ([주식회사 등의 외부감사에 관한 법률 제6조 제6항](https://www.law.go.kr/법령/주식회사등의외부감사에관한법률)).

## 수정분개 반영 (정산표·정산표-CF·보고서 재무제표)

[리드시트·거래처 명세] 카드 아래 [수정분개 반영]에서 한다. 명령으로는 `python -m auditautopilot adjust 조서_리드시트.xlsx --template -o 양식.xlsx`
(양식), `python -m auditautopilot adjust 조서_리드시트.xlsx 수정분개.xlsx -o 결과.xlsx`(반영).

1. [수정분개 양식 내려받기]: 채운 조서 TB 탭의 계정과목 목록이 들어간 양식. 번호가 같은 줄이 한 분개이고, 계정과목은 목록에서 고른다.
   차감계정은 `감가상각누계액(건물)`처럼 앞 계정 이름이 붙어 겹치지 않는다. 시산표에 없는 계정(예: 대손상각비)은 직접 적고
   '새 계정 묶음'을 고른다(안 고르면 이름으로 짐작하고 결과에 알려 줌).
2. 채운 양식을 올리면 조서 끝에 탭 아홉 개가 생긴다. 모든 금액은 수식이라 셀을 따라가며 검증할 수 있다.
   - AJE: 올린 수정분개 그대로.
   - 정산표: 수정전(`=TB!D·H`) + 수정분개(AJE 탭 SUMIFS) = 수정후. 손익계산서·재무상태표 칸으로 나누고 당기순이익으로 대차를 맞춘다.
     아래 검증 칸 다섯 개가 모두 0이어야 한다(수정전·수정분개·수정후·재무상태표 대차, TB에 없는 과목).
   - 수정후BS: 정산표 재무상태표 칸을 묶음별 소계·총계로. 전기는 BS 탭. 결산 전 시산표면 당기순이익을 이익잉여금 아래 줄로 더한다.
   - 수정후IS: 정산표 손익계산서 칸으로 매출총이익·영업이익·법인세차감전·당기순이익. 전기는 IS 탭의 같은 과목명.
   - 정산표-CF: 회계사 조서의 현금흐름 정산표 양식. 재무상태표 계정마다 전기·당기·증감액을 두고 증감을
     영업(Dr 유출·Cr 유입·자산부채변동)·투자(Dr·Cr)·재무(Dr·Cr)·비현금흐름(Dr·Cr) 칸에 나눈다. 비고 칸은 계정마다
     '나눈 금액 - 증감액'이라 0이면 다 나눈 것이다(현금 계정만 0이 아님). 노란 칸은 자동 배분 수식이다:
     운전자본 → 자산부채변동, 감가상각비·대손상각비·퇴직급여·무형자산상각비 → 짝 계정(누계액·충당금)의 Cr(유입),
     유형자산처분손익 → 첫 유형자산, 대여금·금융상품·유형자산 등 → 투자, 차입금·보증금 → 재무, 이익잉여금 감소 → 재무 Dr(배당 등),
     자본조정·기타포괄 → 비현금흐름. 아래에 열 합계, 활동별 현금흐름(영업 = H+I-G, 투자 = K-J, 재무 = M-L), 검증 세 칸,
     현금 없는 손익 대사표(손익계산서 금액 vs 정산표-CF 배분, 차액)가 있다. 취득·처분 총액은 회계사가 Dr·Cr 칸에 고쳐 적는다.
   - 보고서 BS·보고서IS: 한 해에 열 2개(안쪽 = 계정, 바깥 = 소계·합계), 당기 C·D열, 전기 E·F열. 자산은 (1)당좌자산·(2)재고자산,
     (1)투자자산·(2)유형자산… 순서. 금액이 0인 계정은 뺀다. 아래 검증 칸은 수정후BS·IS와 맞는지 본다.
   - 자본변동표: 자본 묶음별 전기초 → 전기말 → 당기초 → 당기순이익·배당 등 → 당기말. 전기 배당 등은 노란 칸에 적으면 전기초가 거꾸로 계산된다.
   - 보고서현금흐름표: 정산표-CF 칸을 가리키는 간접법 현금흐름표(1. 당기순이익, 2. 현금 유출이 없는 비용 가산, 3. 현금 유입이 없는
     수익 차감, 4. 자산부채의 변동, 투자·재무 유입·유출). G열 검증 칸은 정산표-CF 합계와 맞는지 본다. 전기 E·F열은 비워 둔다.
3. 리드시트(○1000) I열(Audited F/S)은 `=H + '정산표'!N`(G/L + 수정분개)으로 바뀐다. 새 계정은 TB 탭·리드시트에는 없다.
4. 다시 올리면 아홉 탭을 새로 만든다(전에 만든 현금흐름정산표 탭은 지운다). 결과 조서와 올린 수정분개는 '조서' 폴더에 저장된다.

## 주석 자료요청 양식 · 재무제표·주석 초안

수정분개를 반영하면 [수정분개 반영] 아래에 ① 주석 자료요청 양식 내려받기 → ② 회사가 채운 주석 자료 올리기 → ③ 재무제표·주석 초안(워드)이 생긴다.
명령: `python -m auditautopilot notes 결과.xlsx -o 주석자료.xlsx`, `python -m auditautopilot fs 결과.xlsx --notes 채운주석자료.xlsx -o 재무제표.docx`.

- 재무제표·주석 초안(.docx): 재무상태표·손익계산서·자본변동표·현금흐름표(간접법)를 정산표 금액(조서의 수정후BS·수정후IS·정산표-CF 탭과
  같은 합계)으로 만들고, 받은 주석 자료의 시트마다 주석 하나를 표로 넣는다. 아무것도 안 채운 열은 빼고, 합계 줄은 다시 더한다.
  '없음'만 적힌 주석은 "해당사항이 없습니다", 비어 있는 회사 작성 주석과 회사 개요·회계정책은 [ ]로 둔다. 당기·전기 모두 0인 계정은 뺀다.
  모두 워드 표라 그대로 복사해 붙여 넣을 수 있다. 감사보고서 의견 문단은 넣지 않는다.

- 주석 자료요청 양식(.xlsx): 목차 + 주석별 시트. 둘로 나뉜다.
  - 정산표 금액 채움(회색 칸 = 수정분개 반영 금액): 현금·금융상품, 매출채권(연령분석)·대손충당금 변동, 재고자산, 유형·무형자산 변동
    (기초·기말 장부금액), 차입금, 퇴직급여, 자본금, 판관비, 영업외손익, 법인세. 회사는 노란 칸(내역·변동·조건)만 채운다.
  - 회사 작성: 특수관계자 현황·거래, 담보 제공 자산, 보험, 토지 공시지가(토지가 있을 때, 장부금액은 미리 넣음), 지급보증, 약정,
    소송·우발부채, 사용제한 예금, 주주, 리스, 보고기간후사건.
  - 계정이 없는 주석은 넣지 않는다.
- (명령 `report`만) 감사보고서 문구 초안(.docx): 조서 '일반사항' 탭(회사명·회계법인명·당기/전기 결산일·감사종료일)으로 감사기준서 700 예시 꼴의 문구를 채운다.
  의견은 적정·한정·부적정·의견거절 중 고르고, 적정이 아니면 근거 단락을 [ ]로 비워 둔다. 기타사항(전기 감사인)도 [ ]로 둔다.
  뒤 페이지에 정산표 기준 재무상태표·손익계산서 요약을 붙인다(회사 재무제표와 대사용, 보고서에는 넣지 않음).
  회계법인 표준 문구와 한 번 대조해 쓴다.

## 메일 계정

IMAP(받기)·SMTP(보내기)를 쓰는 메일이면 된다. 계정은 여러 개 넣을 수 있다. 받은 메일은 모든 계정에서 확인하고(두 계정에 함께 온 같은 메일은 한 번만 처리), 보낼 때는 기본 계정 또는 회사 화면에서 회사마다 정한 계정을 쓴다. 설정 > 메일 계정에서 Gmail, 다음(한메일), 네이버를 고르면 서버 주소가 채워지고,
그 밖의 메일은 서버 주소를 직접 넣는다. 비밀번호는 보통 각 메일 보안 설정에서 만든 '앱 비밀번호'를 쓴다.
- [Gmail을 다른 메일 프로그램에 추가하기 (Google 고객센터)](https://support.google.com/mail/answer/7126229?hl=ko)
- 다음·네이버 서버 값: [Daum](https://www.getmailbird.com/setup/access-daum-net-via-imap-smtp), [Naver](https://www.getmailbird.com/setup/access-naver-com-via-imap-smtp)

비밀번호는 데이터베이스에 저장하지 않는다. 프로그램이 켜져 있는 동안 메모리에만 두고, 윈도우에서는 원하면
'자격 증명 관리자'(제어판)에 `auditautopilot:메일주소`로 저장한다.

[연결 시험]은 보내기(SMTP)와 받기(IMAP)를 따로 시험해서 어디서 막혔는지 보여준다. 보내기가 465(SSL)에서 끊기면
587(STARTTLS)로, 587에서 끊기면 465로 한 번 더 시도하고, 된 포트를 그 계정 설정에 저장한다.
- `Connection unexpectedly closed`: 로그인 전에 연결이 끊긴 것이다. 비밀번호 문제가 아니라 PC 백신의 메일 보호(SSL 검사)나
  방화벽이 포트를 막는 경우가 많다. 다음·네이버는 웹메일 설정에서 IMAP/SMTP 사용을 켜야 한다.
- `535`/`AUTHENTICATIONFAILED`: 비밀번호 거절. Gmail은 2단계 인증을 켠 뒤 만든 16자리 앱 비밀번호를 넣는다
  ([앱 비밀번호로 로그인 (Google 고객센터)](https://support.google.com/accounts/answer/185833?hl=ko)).

## 관리 화면 쓰는 순서

1. `python -m auditautopilot serve` → 브라우저에서 http://127.0.0.1:8765
2. **설정**: 회계법인 이름, 작성자, 연락처, 저장 루트 폴더, 폴더 규칙, 공휴일
3. **회사**: 회사코드·회사명·담당자 이메일 등록
4. **감사 등록**: 감사구분과 현장감사 일정을 넣으면 요청 목록이 만들어진다
5. **현황**: 오늘 보낼 메일 → 미리보기 → 아웃룩으로 열기(.eml) → 보낸 뒤 [보냄으로 표시]
6. 받은 자료는 감사 화면에서 올리거나 수신함 폴더에 넣고 [수신함 정리]

데이터는 `data/audit.db` 한 파일에 저장된다. 기본으로 이 PC에서만 접속되며,
팀 공유(`--host 0.0.0.0`)는 로그인 기능을 붙이기 전까지 사무실 내부망에서만 쓴다.

## 지원하는 파일 형식

- **세무사랑 '재무제표 등' 묶음**: TB, BS, PL, 분개장, 계정코드 이름의 거래처원장 시트
- **더존 분개장**: 전표일자 | 전표번호 | 구분 | Code | 계정과목 | 차변 | 대변 | 거래처 | Code | 적요
- **더존 재무상태표·손익계산서(과목별)**: 계정코드가 없어 과목명으로 구분한다. 차감계정은
  `대손충당금(외상매출금)`, `감가상각누계액(건물)`처럼 앞 계정 이름을 붙인다. 분개장을 함께 주면 계정코드를 채운다.
- **더존 거래처원장(잔액)**: 거래처 | 전기(월)이월 | 차변 | 대변 | 잔액. 파일에 계정이 없으므로
  합계 잔액을 재무상태표 계정 금액과 맞춰 어느 계정인지 찾는다(같은 금액이 여럿이면 전기이월까지 비교).
- 더존 파일은 여러 개를 한 번에 주면 종류를 알아서 맞춘다. 분개장이 재무제표 기간보다 길면 기간 끝까지만 쓴다.
- **더존 합계잔액시산표**: 차변(잔액, 합계) | 계정과목 | 대변(합계, 잔액). 과목 `[108] 외상매출금` 또는 `[0103] 보통예금`,
  구분 줄 `◀유동자산▶`·`◁당좌자산▷` 또는 `1.유동자산`·`＜당좌자산＞` 두 모양 모두 읽는다.
  거래처원장은 시산표 잔액과 먼저 맞춰 계정을 찾고, 파일 이름이 계정명(예: `미지급금.xlsx`)이면 그것을 따른다.

## 조서 정리 방식

조서 파일은 openpyxl로 다시 저장하면 도형(화살표 등)이 사라지기 때문에, 엑셀 내부 XML 중
시트 목록·이름 정의·목차 시트만 고치고 나머지는 그대로 복사한다.

- **절차서 탭**: 숫자가 없는 인덱스 탭(A, B, DER, BB,DD)은 숨긴다. 일반사항·총괄·공시점검·TB·BS·IS, 첫 인덱스 탭보다
  앞에 있는 탭(조회서·assign·PL 등), 정산표·보고서 탭은 항상 보인다. 인덱스 탭 사이에 끼운 보조 탭(예: C1100 뒤 '금융평잔')은
  바로 앞 인덱스를 따라간다.
- **담당자 보기**: 총괄 시트의 `인덱스 | 계정과목 | 담당자` 표를 읽어, 다른 사람 인덱스의 탭을 숨긴다. 조서에 `assign` 탭
  (계정과목 줄 × 담당자 열, 맡은 칸에 V)이 있으면 계정과목 이름이 겹치는 인덱스에 그 담당자를 붙인다. 한 인덱스에 여럿이면 쉼표.
- **관리 화면**: 감사 화면 [리드시트] 탭의 '담당자별 조서'에서 인덱스별 담당자를 고쳐 저장하고, [이름 조서] 버튼으로
  그 사람 탭만 보이는 조서를 받는다(수정분개를 반영했으면 그 조서). 맨 앞 목차 탭도 그 사람 기준으로 다시 만든다.
- **이름 정의 정리**: `#REF!`로 깨진 이름 중 어느 수식에서도 쓰이지 않는 것만 지운다.
  `--aggressive-names`를 주면 쓰이지 않는 숨김 이름도 지운다.
- 숨긴 탭은 엑셀에서 탭 우클릭 > 숨기기 취소로 언제든 다시 볼 수 있다.
