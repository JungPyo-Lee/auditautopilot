# auditautopilot 사용설명서 (0.2.1)

회계감사 중간·기말 업무를 돕는 프로그램입니다. 브라우저에서 쓰는 관리 화면과, 파일을 바로 처리하는 명령으로 되어 있습니다.

## 기능 요약

| 구분 | 기능 | 하는 일 |
| --- | --- | --- |
| 관리 화면 | 회사·감사 등록 | 회사·담당자·업종(일반·건설)을 등록하고, 감사를 만들면 자료요청 목록이 자동으로 생깁니다 |
| 관리 화면 | 업무 진행 막대 | 감사마다 7단계(자료요청 → 메일 일정 → 받은자료 → 질문서 → 채권채무조회 → 리드시트 → 수정분개·재무제표) 진행을 녹색·빨간색으로 표시 |
| 관리 화면 | 자료요청(PBC) | 항목별 상태·요청일·수령일 관리, 요청 리스트 올리기, 엑셀 내려받기 |
| 관리 화면 | 메일 일정·발송 | 현장감사 D-7 최초 요청, D-3부터 미제출 항목만 매일 독촉. 바로 보내기·재발송 버튼 또는 아웃룩용 .eml |
| 관리 화면 | 메일 받기·자료 정리 | 메일함 첨부를 폴더 규칙대로 저장하고 요청 항목을 '수령' 처리 |
| 관리 화면 | 질문서 | 작성 → 승인 → 발송 → 답변 → 종결. 장부로 증감·대손·원가율·특이분개·표본 질문 초안 자동 작성 |
| 관리 화면 | 채권채무 조회 | 한공회 전자조회 회신현황을 가져와 대사표, 미회신 금액·회신률 경고 |
| 관리 화면 | 리드시트·거래처 명세 | 합계잔액시산표·재무제표·거래처원장으로 조서 TB·BS·IS 탭과 ○1100 명세 채우기, 전체계정 조서 내려받기 |
| 관리 화면 | 담당자별 조서 | 감사 참여자 명단, 매출및매입·기타계정 카테고리로 배정, 사람별로 맡은 탭만 보이는 조서 |
| 관리 화면 | 수정분개·재무제표 | 수정분개 → AJE·정산표·수정후BS/IS·정산표-CF·보고서 BS/IS·자본변동표·현금흐름표 탭(모두 수식) |
| 관리 화면 | 주석·초안 | 주석 자료요청 양식, 재무제표·주석 초안(워드) |
| 명령 | 조서 정리 | 절차서 탭 숨김, 담당자 탭만 보기, 목차, 깨진 이름 정의 정리, 인쇄용 사본 |
| 명령 | 중요성·분석·표본 | 중요성(중간감사 연환산), 전기 대비 분석적 검토, 표본추출(전수·무작위·체계적·MUS) |
| 명령 | 데이터 불러오기 | 세무사랑 묶음, 더존 분개장·재무제표·거래처원장·시산표 정리(주민번호 뒷자리 가림) |
| 명령 | 감사보고서 문구 초안 | 조서 일반사항 탭으로 의견 4종 문구 초안(워드) |

## 1. 설치

### 필요한 것

- 윈도우 10 또는 11
- 파이썬 3.10 이상 ([python.org 내려받기](https://www.python.org/downloads/windows/)). 설치 첫 화면에서 **Add python.exe to PATH**를 체크합니다.

> 회사 PC 앱 제어 때문에 이 패키지는 exe나 DLL 없이 파이썬 파일만 들어 있습니다. pip 설치도 필요 없습니다.

### 압축 풀기

1. `auditautopilot-0.2.1-windows.zip`을 원하는 폴더(예: `D:\감사도구`)에 풉니다. 바탕화면·문서 폴더도 됩니다.
2. 폴더 안 구성은 다음과 같습니다.

| 파일·폴더 | 쓰임 |
| --- | --- |
| `실행.bat` | 관리 화면을 엽니다 (두 번 클릭) |
| `명령창.bat` | 명령으로 파일을 처리할 때 엽니다 |
| `pip설치.bat` | (선택) 사용자 계정에 설치. 하지 않아도 됩니다 |
| `app` | 프로그램 파일 (고치지 마세요) |
| `wheels` | pip설치.bat이 쓰는 설치 파일 |
| `data` | 감사 데이터(audit.db)와 받은 자료·조서가 저장됩니다 |
| `사용설명서.html` | 이 설명서 |

### 처음 실행

1. `실행.bat`을 두 번 클릭합니다. 검은 창이 뜨고 브라우저에 관리 화면(http://127.0.0.1:8765)이 열립니다.
2. 처음 한 번 보안 경고(“게시자를 확인할 수 없습니다” 또는 “Windows의 PC 보호”) 창이 뜨면 **실행**(또는 **추가 정보 → 실행**)을 누릅니다. 압축 파일 우클릭 → 속성 → **차단 해제**를 체크하고 풀면 이 창이 뜨지 않습니다.
3. 검은 창은 프로그램이 도는 동안 열어 둡니다. 닫으면 관리 화면도 끝납니다.

> 브라우저가 안 열리면 주소창에 http://127.0.0.1:8765 를 직접 넣습니다. 8765 포트를 다른 프로그램이 쓰고 있으면 명령창에서 `aap serve --port 8766`처럼 바꿉니다.

## 2. 처음 설정 (설정 메뉴)

| 칸 | 넣을 것 |
| --- | --- |
| 보내는 사람 | 회계법인 이름, 작성자, 연락처, 보내는 메일 주소 |
| 일정 | 최초 요청 D-n(기본 7), 독촉 시작 D-n(기본 3), 제출기한, 주말 제외, 공휴일 |
| 저장 폴더 규칙 | 루트 폴더(기본 `data/감사`), 폴더 규칙. 미리 만든 규칙에서 고를 수 있습니다 |
| 메일 문구 | 요청·독촉·질문서 메일 문구, 질문서 회신기한 |
| 전자조회 계정 | 한공회 채권채무 전자조회 본인 아이디·비밀번호. [로그인 시험] |
| 메일 계정 | Gmail·다음·네이버를 고르면 서버가 채워집니다. 비밀번호는 앱 비밀번호. [연결 시험] |
| 보내기·확인 설정 | 자동 발송(기본 꺼짐), 발송 시각, 메일함 확인 주기 |

- Gmail(회사 도메인 포함)은 2단계 인증 후 만든 16자리 앱 비밀번호를 넣습니다 ([앱 비밀번호로 로그인, Google 고객센터](https://support.google.com/accounts/answer/185833?hl=ko)).
- 메일·전자조회 비밀번호는 데이터베이스에 저장하지 않습니다. 프로그램이 켜진 동안만 기억하고, 원하면 윈도우 자격 증명 관리자에 저장합니다.
- 전자조회는 이용약관상 아이디를 함께 쓰면 안 되므로 팀원마다 자기 아이디를 넣습니다.

## 3. 감사 한 건 진행하기

### 3-1. 회사와 감사 등록

1. **회사** 메뉴에서 회사코드·회사명·담당자 이메일·업종을 등록합니다. 회사마다 보내는 메일 계정을 따로 정할 수 있습니다.
2. 회사 화면에서 감사를 등록합니다(감사구분 중간·기말, 현장감사 시작·종료일). 업종 양식(일반·건설)으로 자료요청 목록이 만들어집니다. 쓰는 요청 목록 엑셀이 있으면 그 양식을 올려도 됩니다.
3. 감사 화면 위쪽의 7단계 진행 막대에서 각 단계를 누르면 해당 탭으로 갑니다. 자동 판정이 맞지 않으면 단계마다 [완료]·[해제]를 직접 누를 수 있습니다.

### 3-2. 자료요청 (PBC)

- 항목마다 상태(미요청·요청·일부수령·수령·검토완료·보완요청·해당없음)와 비고를 고치고 [상태 저장].
- [새 요청 리스트 올리기]로 엑셀 목록을 추가하거나 아직 요청하지 않은 항목을 바꿉니다.
- 목록은 엑셀로 내려받을 수 있습니다.
- [자료요청 메일 재발송 (미제출 n건)]을 누르면 확인 창 한 번 뒤 아직 받지 못한 자료(미요청·요청·일부수령·보완요청)만 담은 자료요청 메일이 첨부 목록과 함께 바로 나갑니다. 아직 최초 요청을 안 보냈으면 [자료요청 메일 지금 보내기]로 보입니다. 메일 계정과 회사 담당자 이메일이 있어야 합니다.

### 3-3. 메일 일정·발송

- 현장감사 D-7에 최초 요청, D-3부터 당일까지 미제출 항목만 매일 독촉 메일이 잡힙니다(주말·공휴일 건너뜀).
- 감사 화면 [메일 일정] 표의 줄마다 [지금 보내기](안 보낸 메일)·[재발송](보낸 메일) 버튼이 있어 미리보기 없이 바로 보낼 수 있습니다. 재발송은 그때 기준 미제출 자료만 담습니다.
- **현황** 화면에 오늘 보낼 메일이 뜹니다. [미리보기] → [지금 보내기](메일 계정 연결 시) 또는 아웃룩용 .eml 내려받기 → 보낸 뒤 [보냄으로 표시].
- 제목에 `[C001-2026-기말]` 같은 꼬리표가 붙어, 회사가 답장하면 같은 감사로 들어옵니다.

### 3-4. 받은 자료

- 메일 계정을 연결하면 정한 주기마다 메일함을 확인해 회사 담당자 메일의 첨부를 폴더 규칙대로 저장합니다(읽음 표시는 바꾸지 않음).
- 화면에서 파일을 올리거나 수신함 폴더에 넣고 [수신함 정리]를 눌러도 됩니다. 파일 이름의 요청번호·자료명으로 항목을 찾아 '수령' 처리하고, 못 찾은 파일은 미분류 폴더로 갑니다.
- 대용량 메일 링크는 감사 화면에 모아 보여 줍니다. 직접 내려받아 수신함에 넣으면 됩니다.

### 3-5. 질문서

1. 질문을 직접 넣거나, [장부로 증감분석 질문 초안 만들기]에 재무상태표·손익계산서(과목별, 전기 포함)·분개장·거래처원장(또는 세무사랑 묶음)과 중요성 금액을 넣습니다.
2. 자동 초안: 중요성 이상 증감(중간감사는 연환산), 매출채권 전기=당기 시 대손충당금, 매출원가율 ±3%p, 특이분개 최대 10건, 매출·매입전표 표본 5건씩 증빙 요청.
3. 채권채무 조회의 불일치·미회신 건으로도 초안을 만들 수 있습니다.
4. 상태 흐름: 작성 → 승인대기 → 승인 → 발송 → 답변받음 → 종결. 승인한 질문만 메일로 나가며, 답변 칸이 있는 질문서 엑셀이 첨부됩니다.
5. 회사가 채운 질문서 엑셀을 메일로 보내면 답변이 자동으로 들어갑니다. [답변 엑셀 반영]으로 직접 올려도 됩니다.

### 3-6. 채권채무 조회 (전자조회)

- [전자조회에서 지금 가져오기]: 회사명·연도로 프로젝트를 찾아 연결하고 회신현황·미회신현황을 받아 대사표를 만듭니다. 못 찾으면 목록에서 고릅니다.
- 사이트에서 내려받은 회신현황 엑셀을 올려도 됩니다. 재무상태표·거래처원장을 함께 올리면 발송금액과 장부 잔액을 거래처별로 다시 맞춥니다.
- 미회신 금액이 중요성을 넘거나 회신률이 기준(기본 80%)보다 낮으면 카드가 빨간 테두리로 바뀝니다.
- 대사표 시트: 요약 / 불일치_차이조정 / 미회신_대체절차 / 명세 / 참고. 외화 건은 원화 합계에서 빠지고 따로 알려 줍니다.
- 금융기관 조회는 아직 없습니다.

### 3-7. 리드시트·거래처 명세

1. 조서 양식과 회사 자료(합계잔액시산표, 재무상태표·손익계산서 과목별, 거래처원장들)를 올립니다.
2. TB 탭에 시산표 계정이 묶음별로 들어가고, BS·IS 탭에 당기·전기가 들어가 리드시트(○1000)가 수식으로 계산됩니다.
3. 거래처원장은 ○1100 탭 아래에 거래처별 명세와 시산표 잔액 차이로 들어갑니다(칸이 모자라면 행을 넣음).
4. 양식의 합계 수식 누락·차감계정 수식은 자동으로 고칩니다. 넣을 곳을 못 정한 계정은 결과 목록에 나옵니다.
5. [전체계정 조서 내려받기]: 담당자 배정과 관계없이 모든 계정 탭이 보이는 조서(절차서 탭만 숨김, 맨 앞 목차)입니다. 수정분개를 반영했으면 반영한 조서로 받습니다. 수정분개 반영과 재무제표·주석 초안은 늘 이 전체계정 조서로 만듭니다.

### 3-8. 담당자별 조서

1. 리드시트 탭 '담당자별 조서' 카드에서 감사 참여자 명단을 저장합니다(다음 감사에 미리 채워짐).
2. 인덱스는 '매출및매입'(매출채권·미수금·매입채무·미지급금·선수금·매출·원가·판관비)과 '기타계정'으로 나뉩니다. 줄마다 카테고리를 바꿀 수 있습니다.
3. [카테고리별로 한 번에 배정]에서 카테고리 전체나 묶음(채권·채무·매출·원가·판관비)을 한 사람에게 [바꾸기]·[담당자 추가]합니다. 개별 인덱스는 체크 칸으로 고칩니다.
4. [홍길동 조서]처럼 사람 이름이 붙은 버튼으로 그 사람이 맡은 탭만 보이는 조서를 받습니다. 숨긴 탭은 엑셀에서 탭 우클릭 → 숨기기 취소로 볼 수 있습니다.

### 3-9. 수정분개·재무제표

1. [수정분개 양식 내려받기]: 조서 TB 탭 계정과목 목록이 들어간 양식입니다. 번호가 같은 줄이 한 분개입니다.
2. 채운 양식을 올리면 조서 끝에 AJE, 정산표, 수정후BS, 수정후IS, 정산표-CF, 보고서 BS, 보고서IS, 자본변동표, 보고서현금흐름표 탭이 생깁니다. 모든 금액이 수식이고 검증 칸이 0이면 맞습니다.
3. 리드시트 I열(Audited)은 G/L + 수정분개로 바뀝니다.
4. 이어서 ① 주석 자료요청 양식 내려받기 → ② 회사가 채운 주석 자료 올리기 → ③ 재무제표·주석 초안(워드)을 만듭니다.

## 4. 명령으로 쓰기 (명령창.bat)

`명령창.bat`을 열면 `aap` 뒤에 명령을 적어 바로 실행할 수 있습니다. 파일을 창에 끌어다 놓으면 경로가 들어갑니다.

| 명령 | 예 |
| --- | --- |
| 조서 정리 | `aap workpaper prepare 조서.xlsx -o 조서_작업용.xlsx --assignee 홍길동` |
| 인쇄용 사본 | `aap workpaper print-copy 조서.xlsx -o 조서_인쇄용.xlsx` |
| 세무사랑 정리 | `aap import semusarang 재무제표등.xlsx -o 정리.xlsx` |
| 더존 정리 | `aap import douzone 재무상태표.xlsx 손익계산서.xlsx 거래처원장.xlsx -o 정리.xlsx` |
| 중요성 | `aap materiality 재무제표등.xlsx --benchmark 매출액 --overall-pct 1 -o 중요성.xlsx` |
| 분석적 검토 | `aap analytics 재무제표등.xlsx --threshold-amount 858395000 -o 분석적검토.xlsx` |
| 표본추출 | `aap sample 재무제표등.xlsx --account 108 --threshold 1000000000 --method mus --n 25 -o 표본.xlsx` |
| 채권채무 대사 | `aap confirm 회신현황.xlsx 재무상태표.xlsx 거래처원장.xlsx -o 채권채무조회.xlsx` |
| 리드시트 | `aap leadsheet 조서.xlsx 합계잔액시산표.xlsx 재무상태표.xlsx 손익계산서.xlsx -o 조서_리드시트.xlsx` |
| 수정분개 양식·반영 | `aap adjust 조서_리드시트.xlsx --template -o 양식.xlsx` / `aap adjust 조서_리드시트.xlsx 수정분개.xlsx -o 결과.xlsx` |
| 주석 자료요청 | `aap notes 결과.xlsx -o 주석자료.xlsx` |
| 재무제표·주석 초안 | `aap fs 결과.xlsx --notes 채운주석자료.xlsx -o 재무제표.docx` |
| 감사보고서 문구 초안 | `aap report 결과.xlsx --opinion 적정 -o 감사보고서.docx` |

명령마다 `aap 명령 --help`로 선택 사항을 볼 수 있습니다. 원본 파일은 고치지 않고 항상 새 파일로 저장합니다.

## 5. 팀과 같이 쓰기

- 기본은 이 PC에서만 접속됩니다.
- 사무실 내부망에서 팀원이 같이 보려면 명령창에서 `aap serve --host 0.0.0.0 --db data\audit.db`로 열고, 팀원은 `http://내PC주소:8765`로 접속합니다. 아직 로그인 기능이 없으므로 외부망에 열지 않습니다.
- 윈도우 방화벽이 묻는 창이 뜨면 '개인 네트워크'만 허용합니다.

## 6. 새 버전으로 바꾸기와 백업

- 데이터는 `data` 폴더 하나에 있습니다(`audit.db`와 루트 폴더 `data\감사`).
- 새 버전: 새 zip을 다른 폴더에 풀고, 프로그램을 끈 상태에서 예전 폴더의 `data` 폴더를 새 폴더로 통째로 옮깁니다.
- 예전에 저장소에서 직접 실행하던 경우(`python -m auditautopilot serve`), 그 폴더의 `data` 폴더를 옮기면 그대로 이어집니다. 설정의 루트 폴더를 다른 경로로 바꿔 두었다면 그 폴더는 그대로 쓰입니다.
- 백업: 프로그램을 끈 뒤 `data` 폴더를 복사합니다.

## 7. 문제가 생기면

| 증상 | 해결 |
| --- | --- |
| "파이썬을 찾지 못했습니다" | 파이썬 3.10 이상을 설치하고 Add python.exe to PATH를 체크한 뒤 다시 실행 |
| 실행.bat이 바로 꺼짐 | 명령창.bat을 열고 `aap serve`를 입력해 나오는 오류 문구를 확인 |
| 브라우저가 안 열림 | 주소창에 http://127.0.0.1:8765 입력 |
| 포트 사용 중 오류 | 이미 켜 둔 검은 창이 있는지 확인하거나 `aap serve --port 8766` |
| 메일 `Connection unexpectedly closed` | 비밀번호가 아니라 백신 메일 보호·방화벽 문제인 경우가 많음. [연결 시험]이 465·587을 번갈아 시도 |
| 메일 `535`·`AUTHENTICATIONFAILED` | 앱 비밀번호를 다시 만들어 넣기 |
| 전자조회 자동입력방지 문자 | 사이트에서 한 번 직접 로그인한 뒤 다시 시도 |
| 엑셀 파일 사용 중(WinError 32) | 엑셀에서 그 파일을 닫고 다시 누르기 |
| 조서의 도형이 사라질까 걱정 | 조서 정리는 시트 목록·이름 정의만 고치고 나머지는 그대로 복사하므로 도형이 남습니다 |

## 8. 자료 보안

- 실제 회사 자료는 `data` 폴더 안에만 둡니다. 이 폴더를 메일·메신저로 통째로 보내지 않습니다.
- 데이터 불러오기는 주민등록번호 뒷자리를 가립니다.
- 프로그램은 외부로 자료를 보내지 않습니다. 메일 발송, 메일함 확인, 전자조회 가져오기만 인터넷을 씁니다.
